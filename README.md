## The entry

One number, digits only: my honest count of open browser tabs.

**47**

A non-round number, because a real count is rarely tidy. High enough to
surprise, low enough to believe — the tab hoard of a genuine browsing
session, not a figure picked to shock.

## How it works

`main.py` writes that single number to `/output/entry.txt` — nothing else.
No words, no explanation, no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
# 47
```
